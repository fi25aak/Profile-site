# Profile Site (HTML, CSS, JavaScript)

A personal profile and portfolio site built with hand-written HTML, CSS and JavaScript. No templates or libraries.

## Pages
- `index.html` About me
- `interests.html` Technical interests
- `portfolio.html` Portfolio with pop-up quick view
- `project.html` Project details (holding page)
- `contact.html` Contact form (client-side validation only)

## Run locally
Open `index.html` in a browser, or run `python -m http.server` and visit http://localhost:8000.

## Accessibility
Built to WCAG 2.2 level AA: skip link, landmarks, one h1 per page, alt text, labelled form fields, visible focus, AA contrast, native `<dialog>` for the pop-up.
