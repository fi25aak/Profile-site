# Furqan Haydar Iqbal: Profile Site

A personal profile and portfolio site, built with plain HTML, CSS and JavaScript (no templates or libraries).

## Pages
- index.html: About me
- interests.html: Technical interests
- portfolio.html: Portfolio, with a pop-up quick view
- project.html: Project details
- contact.html: Contact form (client-side validation only)

## Accessibility
I built the site with accessibility in mind (semantic HTML, a skip link, labelled form fields, alt text and good colour contrast) and tested it with the WAVE extension.

## Running the site
Open index.html in a browser, or use the Live Server extension in VS Code.
